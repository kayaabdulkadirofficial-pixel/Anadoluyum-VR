# Anadoluyum VR

**Türkiye'nin 81 ilindeki doğa, kültür ve şehir rotalarını fotoğraflar, haritalar ve sanal keşif araçlarıyla sunan gezi rehberi.**

## Canlı site

[Anadoluyum VR'yi aç](https://kayaabdulkadirofficial-pixel.github.io/alagokvr/)

## İçerik

- 420 rota, 54 millî park ve 279 tabiat parkı
- Türkçe, English ve Deutsch arayüz seçenekleri
- Fotoğraf galerisi, rota ayrıntıları ve Google Maps konumları
- Masaüstünde `index.html` dosyasını tarayıcıda açarak kullanabilirsiniz.

## Proje deposu

Bu GitHub deposu Anadoluyum VR projesinin kaynak dosyalarını içerir.
